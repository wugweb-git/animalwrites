# Red to Black/Yellow Replacement Guide

Replace all instances across ALL files:

## Text Colors
- `text-[#D32F2F]` → `text-[#F59E0B]` (for emphasis/headings)
- `text-[#D32F2F]` → `text-[#333333]` (for icons)

## Background Colors  
- `bg-[#D32F2F]` → `bg-[#333333]` (for CTA buttons, overlays)
- `bg-[#D32F2F]` → `bg-[#F59E0B]` (for badges, highlights)

## Border Colors
- `border-[#D32F2F]` → `border-[#F59E0B]` (for accents)
- `hover:border-[#D32F2F]` → `hover:border-[#F59E0B]`

## Hover States
- `hover:bg-[#D32F2F]` → `hover:bg-[#333333]`
- `hover:text-[#D32F2F]` → `hover:text-[#F59E0B]`
- `#B71C1C` → `#1a1a1a` (darker black for hovers)

## Focus States
- `focus:ring-[#D32F2F]` → `focus:ring-[#333333]`
- `focus:border-[#D32F2F]` → `focus:border-[#F59E0B]`
- `focus:text-[#D32F2F]` → `focus:text-[#F59E0B]`

## Special Cases
- ScrollProgress bar → Keep black #333333
- Timeline elements → Use #F59E0B for accents
- Cards/sections borders → Use #F59E0B/20 for opacity
