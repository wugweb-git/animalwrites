What changed for search

  • Every page now has a search title and description that follow one set of rules. Each title has a single separator, and " – Animal Writes" appears only at the end. Rank Math's own settings now give the same result, so a new item reads correctly even before the daily fill runs, and the preview in WordPress shows real text instead of placeholders.
  • Rank Math scores are meaningful and stored for every item that has a page. Rank Math used to score an empty body. It now scores the text visitors see: the summary, source link, categories and related links. The SEO column in WordPress shows a real number.
  • Focus keywords match the titles the way Rank Math reads them. 53 News keywords had lost a hyphen or apostrophe ("animal free" against "Animal-free"), which cost each of them 36 of 100 points. They now use the title's own words, and the workers can no longer produce that mismatch.
  • Internal linking is in place. Item pages show related items, and names inside summaries link to their Library, Directory or place page. All 390 of these links in the sample work. The last orphan page, Ashoknagar's organisation page, is now linked from its district.
  • Filtered lists no longer compete with the main pages.
    • A search inside a list (?q=) is kept out of Google, as Google advises for internal search results.
    • Lists filtered by state or publisher with 3 or more items get their own title, such as "Animal Welfare News from Live Law". Smaller ones are kept out of Google.
    • Lists filtered by type point Google to the matching tag page.
  • AI assistants can read the site. AI crawlers are allowed, as the owner decided, and robots.txt records that. llms.txt now shows today's counts for each section ("1,024 stories on 16 Oct 2026"), not an older copy.
  • News sources are checked. All 1,024 source links were checked slowly and politely. None are dead. 127 sites (for example PETA India and NDTV) block automated checks; they are recorded as blocked, not as dead.

What the owner needs to do

These are host settings or decisions that only the owner can make. Nothing else is pending.
  1. hPanel and CDN: send http://www.animalwrites.in straight to https://animalwrites.in/ (today it takes 2 hops), and turn on HTML edge caching.
  2. Page caching: stop LiteSpeed from clearing the whole site whenever a category or tag is created or edited ("Purge all" on create_term and edit_terms).
  3. Security headers: add X-Content-Type-Options, Referrer-Policy and Permissions-Policy on the host.
  4. Ads above the fold on phones: decide whether the first ad stays above the first card. It slows the main picture on phones.
  5. The 7 guide titles you typed: they are kept as you wrote them. Six of those guides have a focus keyword that is not in the title; change either the title or the keyword.
  6. Hyphens in titles: make the pending decision. A keyword must keep the title's hyphen to count.
  7. "Gaushalas" capitalisation on the Directory band: pick one form for the whole site.
  8. ACF and Web Stories: keep or deactivate them. Web Stories has no published story.
  9. Remove the 10 broken AI keys in Settings → AI models (the red ones), so keyword and summary runs use only working providers.
  10. Google Tag Manager and GA4: import the prepared container, publish it, then mark the key events and add the custom dimensions in GA4 (steps in docs/analytics/).
  11. Rewrite run for the 938 short summaries listed on 15 October.
  12. Inbox → To review: 3 items are waiting.
  13. Rich Results Test: run it on one page per type. It shows a CAPTCHA to automated runs.
  14. Two new guide drafts to approve: "Supreme Court stray dog orders, explained" (13842) and "Injured bird helplines by city" (13843). Also decide whether the injured-animal guide keeps "call 1962" as its keyword.
